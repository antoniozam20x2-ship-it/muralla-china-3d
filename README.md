# Muralla China 3D 🧱 — visor (demo)

Visor 3D low-poly de la Gran Muralla China, hecho con **Three.js**. Arrastra para
girar, rueda o pellizco para acercar. Sin backend, sitio 100% estático.

Todo procedural, sin archivos de modelo:
- **Muralla serpenteante** que sube y baja por lomas (ruta con interpolación suave).
- **Almenas y parapetos** en cada segmento, con camino central.
- **Torres de vigilancia** con remate almenado y techo a dos aguas tipo pagoda.
- **Colinas y montañas** low-poly de fondo, con cielo degradado y niebla.
